SANS SHORTCUT — ANDROID PROJECT

Это исходный Android-проект, который упаковывает игру в обычное приложение с иконкой.
Сам APK в этом архиве не собран: для сборки нужен Android SDK/Gradle.

Самый простой способ получить APK без установки Android Studio:
1. Создайте репозиторий GitHub и загрузите туда содержимое этой папки.
2. Откройте вкладку Actions и запустите workflow "Build Android APK" (или дождитесь сборки после push).
3. В завершённом запуске откройте Artifacts и скачайте SansShortcut-debug-apk.
4. Распакуйте архив на телефоне, нажмите app-debug.apk и подтвердите установку.
5. После установки значок Sans Shortcut появится в списке приложений; добавьте его на главный экран долгим нажатием.

Это debug APK для личного использования. Для публикации в магазине нужна отдельная release-сборка и подпись.
